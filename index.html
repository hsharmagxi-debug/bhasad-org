Action required — bhasad.org is currently hijacked.
Your domain is serving a third-party gambling site ("IDEBET SI PENDOO"). Your Squarespace DNS is pointing to an unauthorized server. Follow the steps below to reclaim and deploy your real site immediately.
01
Download this file
Download the HTML file from the Claude artifact above. Name it index.html. Create a GitHub repo named bhasad-org and push it.
gh repo create bhasad-org --public git add index.html && git commit -m "init" git push
02
Deploy to Vercel
Connect the repo to Vercel. It auto-detects a static HTML project. Deploy takes ~30 seconds. Copy the *.vercel.app URL for DNS testing.
vercel --prod # → https://bhasad-org.vercel.app
03
Fix DNS in Squarespace
In Squarespace Domains → bhasad.org → DNS Settings. Delete any existing A or CNAME records for @ and www. Add these two records:
CNAME @ cname.vercel-dns.com CNAME www cname.vercel-dns.com
04
Add domain in Vercel
In Vercel → Project → Settings → Domains, add bhasad.org and www.bhasad.org. Vercel auto-provisions SSL. DNS propagates in 1–48h.
vercel domains add bhasad.org # SSL auto-provisioned via Let's Encrypt
